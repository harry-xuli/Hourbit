# Hourbit 日程 v0.7.0 交付说明

发布日期：2026-08-22

## 本次更新

- 全面采用重新设计的 A 方案 Hourbit Logo，并同步主程序、任务栏、托盘、安装包与免安装包图标。
- 已错过提醒可重新完成、忽略或延迟 5 分钟；完成后的倒计时立即停止。
- 待办事项采用单层卡片和右键操作，并支持拖动排序与顺序持久化。
- 主时间线、日期选择、分析报告、设置、快速创建及托盘菜单补齐中英文与无障碍文本。
- 合并 v0.6.3 的 Windows App SDK 启动与原生日历修复，避免日期语言绑定导致的启动或日历弹出问题。
