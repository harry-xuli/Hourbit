# Hourbit 开发进度

更新日期：2026-08-13
目标版本：v0.4.0
开发分支：`codex/hourbit-v0.4.0`

## 当前状态

v0.3.0 已发布。v0.4.0 正在进行界面和导航升级；当前所有已提交改动均通过全解决方案 Release 回归，但尚未构建或发布 v0.4.0 安装包。

## 已完成

### v0.4.0 当前批次

- 版本提升为 0.4.0（发布日期 2026-08-13）；
- UI 语言偏好持久保存，Windows 非中文环境默认英文，用户选择优先；
- 顶部加入 `中 / EN`、报告入口，语言切换不改用户录入内容；
- 周视图固定按周一至周日计算，不显示额外的 ISO 周字段；
- 原生日期选择窗可直接查看未来日期，并保持当前日、周或月模式；
- 已完成待办不再显示于右侧清单，但仍保留在统计、报告和历史数据；
- 托盘图标双击恢复并激活现有主页，单击不误触，右键菜单保留；
- 暖色专注主题和更紧凑的顶部布局，同时保留深色系统与高对比适配；
- 快捷键集中管理，新增 F5 刷新并在中英文之间使用同一组按键。

### 已发布基线（v0.3.0）

- schema v5、提醒投递尝试持久化、失败重试和恢复；
- `5点` 与 `下午5点` 的明确时间语义；
- 每天、工作日、每周星期选择器；
- 真实等待/投递失败/已错过状态、编辑后重排和手工刷新；
- Hourbit 安装文件名与安装目录，新包不携带历史客户数据，升级保留本机数据；
- 待办左右分栏和日/周/月彩色图标；
- 通知及重要提醒完成、忽略、稍后提醒后的主时间线自动刷新；
- 紧凑待办行：隐藏可见日期，保留状态图标、标题、重要性和完整无障碍信息；
- 提醒与待办复制，按钮为“复制（Ctrl+D）”，副本创建新记录且不修改原记录；
- 动态倒计时剩余时间；
- 主界面和托盘可打开单实例“使用说明”。
