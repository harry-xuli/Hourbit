# 时刻用户指南

“时刻”是本地优先的 Windows 11 提醒工具。提醒、设置和备份都保存在本机；
第一版不要求账号，也不会在电脑睡眠时唤醒电脑。

> 当前测试发行版未进行代码签名。只从可信的项目发布渠道取得安装包或 ZIP，
> 并先核对同目录 `.sha256` 文件。Windows SmartScreen 可能显示“Windows 已保护
> 你的电脑”；确认发布来源与哈希后，可选择“更多信息”查看发布者和运行选项。
> 不要为了安装本应用而关闭或降低 Windows 安全功能。

## 安装版

1. 下载 `Moment-Setup-x64.exe` 和
   `Moment-Setup-x64.exe.sha256`。
2. 在 PowerShell 中核对哈希：

   ```powershell
   Get-FileHash .\Moment-Setup-x64.exe -Algorithm SHA256
   Get-Content .\Moment-Setup-x64.exe.sha256
   ```

3. 运行安装程序。安装只影响当前 Windows 用户，不要求管理员权限。
4. “时刻”默认安装到
   `%LOCALAPPDATA%\Programs\Moment`，并创建开始菜单快捷方式；桌面快捷方式
   是安装时的可选项。

升级时运行新版安装程序即可。卸载或覆盖升级不会删除
`%LOCALAPPDATA%\Moment\data` 中的用户数据库和备份。

## 便携版

1. 下载 `Moment-Portable-x64.zip` 和相邻的 `.sha256` 文件并核对哈希。
2. 把 ZIP 完整解压到一个可写文件夹；不要直接在 ZIP 预览窗口中运行。
3. 启动 `Moment.App.exe`。

便携版由同目录的 `portable.flag` 标识，数据写入该目录下的 `Data` 文件夹。
移动整个便携文件夹时应先明确退出应用；如果曾启用开机启动，移动后请在设置中
检查并重新确认启动路径。覆盖升级前先备份 `Data` 文件夹。

## 创建第一条提醒

- 从开始菜单或便携目录启动“时刻”。
- 在主时间轴选择“新建”，或者按默认全局快捷键
  `Ctrl+Alt+Space` 打开快速创建。
- 输入明确的中文时间表达并检查预览，再按 Enter 创建。
- 如果默认快捷键已被其他软件占用，应用其余功能仍可使用；请在设置中选择新的
  组合键。

可用命令示例：

```text
20分钟后休息
下午3点半提醒我打电话
明天9点开会
每天18点整理收件箱
每个工作日18点下班
每周五下午4点写周报
```

“晚上”“待会”“下周”等不能唯一确定时间的表达会要求选择具体候选项，不会
直接静默创建。快速创建中可展开详细字段，调整标题、日期、时间、重复规则和提醒
级别。

## 重复提醒

第一版支持每天、工作日（周一至周五）和每周重复。每次只保存下一次发生实例；
完成或忽略当前实例后才生成下一次。编辑或删除重复事项时，请明确选择“只处理
本次”或“本次及以后”。

系统时区变化后，重复事项保持原本的本地钟表时间；单次事项保持原绝对时间点。
节假日不属于“工作日”规则的计算范围。

## 普通与重要提醒

普通提醒使用 Windows 通知，提供完成、10 分钟后提醒和忽略操作。Windows 专注
模式可能延迟或隐藏普通通知；“时刻”不会也不能保证绕过系统专注设置。

重要提醒使用应用置顶窗口和循环声音，提供完成、5/10/30/60 分钟后提醒和忽略。
关闭重要提醒窗口等同于稍后 10 分钟。重要提醒不会绕过锁屏，也不会从睡眠中唤醒
电脑。

如果没有看到普通提醒：

1. 检查 Windows“设置 > 系统 > 通知”中是否允许“时刻”发送通知。
2. 检查专注模式和勿扰状态。
3. 在“时刻”设置中使用测试通知。
4. 重要事项仍应通过应用内窗口处理；不要把测试通知当作锁屏或睡眠场景的证明。

## 托盘、关闭与退出

关闭主窗口只会隐藏到系统托盘，提醒调度继续运行。托盘菜单可重新打开时间轴、
快速创建、创建常用倒计时或进入设置。

只有托盘菜单中的明确“退出”才会停止应用。退出后任何到期提醒都不会触发；如果
还有未到期事项，应用会要求确认。

## 开机启动

开机启动默认关闭，只能由用户在应用设置中选择。安装程序不代替应用写入开机
启动项。便携目录移动后，旧路径不会自动变成新路径，请重新确认设置。

## 备份与恢复

应用每天第一次成功启动后创建一致性数据库备份，并保留最近 7 份。设置页可导出
`.moment-backup` 文件，也可从该文件恢复。

恢复前应用会验证包格式和数据库版本、先备份当前数据，再停止调度、恢复、迁移、
检查并重新扫描提醒。请把导出的备份另存到应用数据目录之外。不要用文件复制工具
覆盖正在运行的 `moment.db`。

数据库损坏时，应用先保留损坏副本，再尝试最近的完整备份；不会直接覆盖唯一
原件。

## 更新

第一版不自动下载或静默安装更新。“检查更新”只在发行构建配置了 HTTPS 发布页面
时显示，并会打开该页面。每次更新都应重新核对发行文件的 SHA-256。

安装版运行新版安装程序进行覆盖升级；便携版先明确退出、备份 `Data`，再覆盖程序
文件，同时保留 `portable.flag` 和 `Data`。

## 睡眠、锁屏与错过事项

“时刻”在应用正常驻留且电脑清醒时调度提醒，但不会设置系统唤醒任务。电脑睡眠
期间提醒不会响；恢复后应用会重新扫描：

- 错过不超过 5 分钟：立即执行原提醒行为。
- 更早的普通提醒：汇总通知并在时间轴标为错过。
- 更早的重要提醒：仍单独进入重要提醒队列。

锁屏、系统通知权限、专注模式和设备电源策略都由 Windows 控制。
