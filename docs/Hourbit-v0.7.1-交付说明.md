# Hourbit 日程 v0.7.1 交付说明

发布日期：2026-08-22

## 本次更新

- 应用 Logo 由 A 方案切换为 B 方案：蓝色日历与勾选，右下角红色时钟。
- 重新生成 16 至 256 像素的多分辨率 Windows ICO，改善任务栏、托盘和标题栏的小尺寸辨识度。
- 安装程序、快捷方式、应用窗口、任务栏、托盘和免安装版统一使用 B 方案 Logo。
- 功能、数据库 schema 和用户数据路径保持不变，安装升级会保留原有数据。

## 签名说明

- 安装版与免安装版内的 `Hourbit.exe` 使用个人证书 `CN=Harry` 签名，并附加可信时间戳。
- 个人自签名证书不等同于商业 CA 证书；未安装该证书的电脑仍可能显示“不受信任的发布者”。
