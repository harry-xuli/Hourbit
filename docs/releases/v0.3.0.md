# Hourbit v0.3.0

Hourbit v0.3.0 是一次生产力与可靠性更新，包含此前尚未发布的 v0.2.2 修复。

## 新功能

- 紧凑待办布局，窄窗口仍优先显示完整主题；
- 提醒与待办可通过“复制（Ctrl+D）”快速创建副本；
- 倒计时在时间线动态显示剩余时间；
- 主界面和托盘新增“使用说明”；
- 日、周、月选择器使用不同颜色图标，提醒与待办左右分栏。

## 可靠性修复

- 完成、忽略或稍后提醒后，主时间线自动刷新；
- 修复普通通知、重要提醒、失败重试、重启恢复和错过状态；
- 支持每天、工作日及按星期选择的每周重复；
- 改进 `5点`、`下午5点`、无年份中文日期以及“日/号”解析；
- 新安装包不携带历史数据库；覆盖升级继续保留本机用户数据。

## 下载

- `Hourbit-Setup-x64.exe`：Windows 11 x64 安装版；
- `Hourbit-Portable-x64.zip`：免安装版；
- 请使用相应 `.sha256` 文件校验下载完整性。

## 安全说明

本版本尚未配置 Authenticode 代码签名，Windows 可能显示“未知发布者”或安全提示。请只从本仓库 Release 页面下载并核对 SHA256；不要关闭或绕过 Windows 安全功能。
