# Hourbit 中文日期“日/号”后缀设计

日期：2026-08-09

## 目标

Hourbit 的中文日期解析器原生支持“日”和“号”两种日期后缀。输入文本不做预替换。

## 行为

- `10月3日 早上6点 闺女办事` 与 `10月3号 早上6点 闺女办事` 解析为相同日期和时间。
- 可选年份同样支持两种后缀，例如 `2026年10月3号 早上6点`。
- 省略年份时，选择不早于当前本地时间的下一次该月日；若今年已过，则选择下一年。
- `早上` 继续按 24 小时制语义解析，示例结果为 06:00。
- 日期和时间 token 从最终标题移除，但不会将输入中的“号”全局替换成“日”。
- 超长、带符号或不可能的月日仍返回无效输入，不能退化为仅按时钟创建提醒。
- 不改变数字日期、文化日期顺序、重复规则、待办规则和数据库结构。

## 实现边界

仅扩展中文合法日期表达式与对应 malformed marker，使二者以相同边界接受 `日|号`。日期选择和时区转换继续复用现有逻辑。

## 验证

- 截图原句 `10月3号 早上6点 闺女办事` 的解析回归测试。
- `日` 与 `号` 等价测试，包括显式年份与无年份日期。
- `号` 形式的异常月日、嵌入标题和标题安全测试。
- 完整中文解析器、Core 以及 Quick Add 接线测试。
- 构建并重启实际 Hourbit，确认进程正常响应。
