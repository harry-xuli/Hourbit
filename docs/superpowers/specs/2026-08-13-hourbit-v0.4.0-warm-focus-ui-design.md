# Hourbit v0.4.0 暖色专注 UI 设计

日期：2026-08-13

状态：用户已确认概念设计，等待书面规格复核

概念图：`assets/hourbit-v0.4.0-warm-focus-ui.png`

## 1. 目标

以用户选定的 C「暖色专注」为基础重构 Hourbit 主界面。设计必须保持克制、易读和可实现，解决未来日期难以查看、快捷键信息分散、已完成待办重复出现，以及最小化后无法直接恢复主页的问题。

本版本只改变界面组织、导航和相关交互，不改变提醒、重复规则、数据保留、通知调度和报告统计的既有业务语义。

## 2. 视觉系统

- 背景使用暖象牙白，内容面板使用白色。
- 文字使用深墨色；主操作使用钴蓝色。
- 焦点事项、选中月份和当前操作使用少量焦橙色。
- 完成使用青绿色，错过和错误使用红色。
- 控件采用细边框、8 像素左右圆角和极弱阴影。
- 状态必须同时具有图标或文字，不能只用颜色表达。
- 保持 Windows 11 高对比度、键盘焦点、UI Automation 名称和 100%–200% 缩放可用。

## 3. 顶部区域

从左到右提供：

1. `Hourbit 日程` 品牌标识；
2. 全局搜索框：`搜索提醒或待办…  Ctrl+F`；
3. `报告` 按钮；
4. `+ 新建` 按钮；
5. `中 / EN` 语言切换；
6. `帮助` 按钮。

搜索框搜索全部有效历史和未来记录，不限当前日、周或月。搜索条件包括标题、日期或日期范围、事项类型、状态、重要性和重复规则。点击搜索结果后，主时间线切换到该事项所在日期并选中真实记录。

顶部只保留一个统一的新建入口。右侧待办栏不再单独显示“添加待办”。新建流程继续根据是否包含时间决定创建提醒或待办。

### 3.1 中英文 UI 切换

顶部右上角在帮助按钮旁显示紧凑的 `中 / EN` 分段控件。当前语言使用焦橙色选中状态，控件可获得键盘焦点并具有明确的屏幕阅读器名称。

语言切换只影响 Hourbit 自身的界面资源，包括：

- 窗口标题、导航、按钮、菜单、ToolTip 和空状态；
- 提醒与待办的系统状态文字、重要性、重复规则及错误提示；
- 设置、使用说明、分析报告和通知中由应用生成的文字；
- 日期范围标签中的月份、星期和界面格式。

语言切换不得改变：

- 用户录入的提醒标题、待办标题、备注或搜索关键词；
- 数据库内容、记录 ID、日期时间、完成状态或重复规则；
- 列表位置、分栏位置、排序和当前选择；
- 输入解析能力。中文自然语言日期与既有数字日期格式在两种 UI 下都继续可用。

切换即时生效，不重启、不重查或重写用户数据。语言选择保存到本机设置并在下次启动恢复。首次启动默认跟随 Windows 显示语言：简体中文环境使用中文，其他环境使用英文。数据库只保存稳定语言代码 `zh-CN` 或 `en-US`，不保存本地化显示文字。

## 4. 时间导航与未来计划

时间导航包含：

- `日 / 周 / 月` 三个分段选项，分别使用蓝色、紫色和橙色日历图标；
- `上一时段`、`今天`、`下一时段`；
- 可点击的当前日期范围按钮；
- 周范围内部按 ISO 8601 计算，但导航行不显示额外的 ISO 说明文字。

范围定义：

- 日：选中的一个自然日；
- 周：ISO 8601 周，星期一至星期日；该规则由日期范围本身表达，不在界面重复显示说明字段；
- 月：自然月第一日至最后一日；
- 主时间线不增加“年”；年范围继续只在报告模块提供。

左右导航按当前模式移动一天、一周或一个月。`今天` 返回系统当前日。点击日期范围打开日历选择器，可直接跳转任何过去或未来日期。日历选择后保持当前日/周/月模式，并计算其所属范围。

范围标签示例：

- 日：`2026年8月13日 星期四`；
- 周：`2026年8月17日 – 8月23日`；
- 月：`2026年8月`。

空白未来范围显示 `此时段暂无计划` 和统一的 `新建`入口，不把用户误导为只能查看今天。

## 5. 今日统计与报告

顶部统计区为两个紧凑的单行指标：

- `过去 7 天已完成`；
- `未来 14 天计划`。

两个指标始终以系统“今天”为基准，不随当前浏览的日、周或月改变，但界面不再显示重复的 `以今天为基准` 辅助文字。点击指标进入相应精确范围的分析报告。顶部 `报告` 按钮是完整分析模块的唯一显式入口，统计区不再重复显示大型 `查看报告` 卡片。报告模块可以选择年范围。

## 6. 主工作区

工作区桌面宽度下采用约 58/42 的左右分栏。

### 6.1 定时提醒

左栏标题为 `定时提醒`，依次分组：

1. `接下来`；
2. `已错过`；
3. `已完成`。

提醒行显示日期、24 小时时间、主题、重复信息、重要性和状态。倒计时及下一项显示基于系统当前时间实时重算的剩余时间。浏览未来范围时，`接下来`展示该范围内计划，而不是只显示今天之前的记录。

### 6.2 待办事项

右栏标题为 `待办事项`，只显示未完成待办。标题获得主要宽度，不在行首显示时间。日期继续保留在无障碍名称、搜索结果和编辑窗口中。

完成待办后：

- 立即从右栏移除；
- 计入“今日完成”和过去 7 天完成统计；
- 可在搜索的完成状态、报告和历史数据中查看；
- 不在待办栏下面重复显示“已完成待办”区域。

选中真实行后显示或启用 `编辑`、`复制`、`完成`和`删除`。所有操作复用既有服务和刷新接缝，不能创建第二套业务逻辑。

窄窗口下优先保证主题可见；两栏空间不足时允许变为上下布局，而不是压缩标题至不可读。

## 7. 快捷键单一来源

默认快捷键为：

| 快捷键 | 操作 |
|---|---|
| `Ctrl+N` | 新建提醒或待办 |
| `Ctrl+D` | 复制当前真实行 |
| `Ctrl+Shift+Space` | 完成当前真实行 |
| `Enter` | 编辑当前真实行 |
| `Delete` | 删除当前真实行 |
| `Ctrl+F` | 聚焦全局搜索 |
| `F5` | 刷新当前时间线 |
| `Esc` | 关闭搜索、菜单或返回主视图 |
| `Ctrl+Alt+Space` | 全局快速创建，允许在设置中修改 |

主界面底栏、按钮 ToolTip、帮助窗口和设置页从同一快捷键描述源生成，不能分别硬编码。事项类快捷键只在真实提醒或待办行获得焦点时生效，不能误用旧选择。

## 8. 托盘与窗口恢复

- 单击托盘图标不执行操作，避免误触；
- 双击托盘图标打开或恢复主界面；
- 右击显示现有托盘菜单；
- 如果主窗口已存在，双击必须恢复最小化状态、激活并置前，不创建第二个窗口；
- 托盘菜单仍保留快速创建、常用倒计时、分析报告、使用说明、设置和退出。
- 托盘双击属于自然桌面行为，不在主界面底栏重复显示操作提示。

## 9. 状态、刷新与错误处理

- 创建、编辑、复制、完成、删除和通知动作成功后请求同一个时间线刷新协调器；
- 当前加载失败时保留最后一次成功结果，显示行内错误和可访问的重试按钮；
- 搜索或时段切换使用代次取消，旧结果不能覆盖新范围；
- 刷新不改变用户当前的日/周/月模式和选中范围；
- 倒计时只更新内存显示，不每秒访问数据库。

## 10. 验收标准

- 可从今天连续导航到未来日、ISO 周和自然月，也可通过日历直接选择未来日期；
- 周范围始终为周一至周日，并正确跨月、跨年；
- 搜索能够找到当前范围外的过去和未来事项，并跳转到正确范围；
- 已完成待办从右栏消失，但统计、搜索和报告仍包含该记录；
- 右栏不出现独立“添加待办”和“已完成待办”区域；
- 顶部报告按钮、两个紧凑统计指标深链和年份报告入口可用，统计区没有重复报告卡片；
- 所有可见快捷键、帮助和 ToolTip 保持一致；
- 托盘图标双击只恢复同一个主窗口；
- 主界面底栏不显示托盘双击提示；
- 日/周/月、搜索、行操作和报告入口均可用键盘及屏幕阅读器操作；
- 100%、150%、200% 缩放和高对比度下无文字裁切、重叠或只靠颜色传达状态。
- `中 / EN` 能即时切换全部当前 UI，重启后保持；用户录入内容、顺序、日期时间和当前选择均不变化；
- 中英文资源键集合完全一致，缺少翻译时测试失败，而不是在生产界面泄漏资源键。

## 11. Hourbit 品牌与兼容身份清理

### 11.1 当前公开内容

GitHub 和开发者可见的当前入口统一使用 Hourbit，包括：

- 解决方案文件改为 `Hourbit.slnx`；
- `src`、`tests` 下的当前项目目录、项目文件、程序集名称和代码命名空间改为 `Hourbit.*`；
- 安装脚本改为 `installer/Hourbit.iss`；
- 当前图标和品牌资源文件改用 `hourbit-*` 名称；
- README、操作手册、发布检查表和当前构建命令使用 Hourbit 文件名；
- GitHub 默认分支不再把 `Moment.slnx`、`src/Moment.*`、`tests/Moment.*` 或 `installer/Moment.iss` 作为当前开发入口。

历史规格和历史提交中出现的 Moment 属于可追溯记录，不批量改写 Git 历史。旧品牌概念图可以移动到明确的 legacy 目录或在历史规格中保留引用，但不能被当前 README 或操作手册当作现行界面。

### 11.2 必须保留的升级兼容身份

以下名称暂时保留在实现常量、迁移代码和兼容文档中，不能直接删除或重命名：

- `%LocalAppData%\Moment\data\moment.db` 现有安装数据路径；
- `.moment-backup` 备份扩展名；
- 既有 Inno Setup AppId；
- 旧 `Moment` 启动项与 `Moment.App.exe` 精确迁移识别；
- 已发布版本使用的单实例、通知组和激活协议标识。

这些兼容名称不得出现在普通用户界面。操作手册只在“旧版本升级与数据位置”章节说明一次，明确它们是为了保留已有数据，不代表当前品牌。安装、升级和卸载均不得删除现有用户数据库。

### 11.3 改名验证

- 新生成的 EXE、ZIP、Setup、开始菜单、桌面快捷方式、窗口、通知和程序集产品信息只显示 Hourbit；
- 从 v0.3.0 原地升级后，旧数据库、设置、备份、提醒和启动配置仍可用；
- 全新安装不创建公开的 Moment 程序目录或快捷方式；
- 仓库扫描把兼容常量、历史规格列入白名单，其他当前文件或用户可见字符串出现 `Moment` 时测试失败。

## 12. 非目标

- 不在主时间线增加年视图；
- 不改变数据库 schema 或提醒调度语义；
- 不恢复尚未完成的 PDF 报告任务；
- 不实现云同步、账户或在线搜索；
- 不删除用户历史数据。
- 不翻译用户录入内容；
- 不迁移或改名现有数据库目录和备份扩展名；
- 不重写历史 Git 提交或历史发布标签。
