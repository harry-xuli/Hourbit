# Hourbit 日/周/月分段选择器设计

日期：2026-08-09

## 目标

将主时间线现有的默认 RadioButton 圆圈改为对齐稳定、颜色可区分的分段选择器，不改变日/周/月筛选行为。

## 已选方案

采用方案 B：三个等高分段项，每项包含图标和文字。

- 日：蓝色日历日图标与“日”。
- 周：紫色周历图标与“周”。
- 月：橙色月历图标与“月”。
- 选中项使用自身颜色的浅色背景、清晰边框和对应前景色。
- 未选中项保持可辨识的类别颜色，但背景为中性。
- 图标与文字在同一水平中线；三个分段的高度、内边距和点击区域一致。
- 不提供“年”选项，年份仍只属于分析报告范围。

## 交互与可访问性

- 继续使用互斥选择语义，ViewModel 命令和 period 值不变。
- 整个分段项均可点击和键盘聚焦。
- 保留现有 Space、方向键和 UI Automation 可访问名称。
- 颜色不作为唯一状态信号：选中项同时具有背景、边框和选中语义。
- 高对比度模式使用系统可见颜色，不能因蓝/紫/橙资源而丢失文字或焦点边框。

## 范围

仅调整主时间线的日/周/月选择器模板、图标资源与对应 WPF 自动化测试。左右周期导航、摘要卡片、列表、快捷键和数据查询不变。

## 验证

- 真实 WPF 控件断言三个分段等高且图标/文字垂直中心一致。
- 日/周/月分别具有稳定的蓝/紫/橙语义资源。
- 鼠标与键盘选择仍更新正确 period，且互斥。
- UI Automation 名称和 RadioButton 选择语义可读取。
- 高对比度资源切换后文字、焦点和选中状态仍可见。
- 完成后重新构建 Hourbit，再生成 0.2.1 安装包和免安装版。
