# “新建提醒”按钮与“时刻之环”Logo 设计规格

## 目标

修正主时间轴右上角“新建提醒”按钮中加号与文字的视觉错位，同时为“时刻”设计一枚
适用于 Windows 11 的应用 Logo。两项调整共用简洁、清楚、圆润的视觉语言，不改变
按钮命令、尺寸、键盘焦点或高对比度行为。

## “新建提醒”按钮

- 保留现有 `NewReminderButton`、命令、自动化名称、最小宽高及颜色资源。
- 用固定 `16 × 16` 的矢量加号替换全角文字“＋”。
- 加号采用两条居中的圆角线段，视觉线宽约 `2 px`，颜色继承按钮前景色。
- 图标与“新建提醒”文字放在同一个水平容器中，二者均垂直居中，间距 `10 px`。
- 删除当前依赖字体度量的 `25 px` 全角字符和负顶部边距。
- 在 100%、125%、150% 和 200% 缩放下保持视觉居中；高对比度下继续使用系统按钮
  前景色。

## App Logo：“时刻之环”

- 方向：抽象时钟圆环加一枚提醒圆点，不包含文字、字母、数字或拟物闹钟支脚。
- 外形：Windows 11 风格的圆角方形底板，主体居中，并为系统裁切留出充足安全区。
- 主体：白色简化时钟圆环和两根指针；提醒圆点位于右上象限，与圆环保持清楚分离。
- 色彩：以应用现有蓝色强调色为核心，可使用克制的深蓝到亮蓝渐变；提醒圆点使用温暖
  的橙红色作为唯一强调色。
- 质感：扁平、干净、矢量友好；允许轻微层次，不使用玻璃、照片纹理、复杂阴影或
  细小装饰。
- 可读性：在 16、24、32、48、64 和 256 像素下，圆环、指针和提醒圆点仍可辨认。
- 生成方式：按用户要求使用 GPT-Image-2 生成方形高质量母版，选择并检查后保存到项目；
  再从母版导出 Windows `.ico` 所需尺寸，并接入应用、任务栏和安装程序。

## 生成提示词约束

使用场景为 `logo-brand`。提示词明确要求：单一居中图标、无文字、无水印、无额外符号、
无设备模型图、无背景场景；圆角方形蓝色底板、白色时钟圆环、右上橙红提醒圆点，并
保留均匀安全边距。

## 验证

- XAML 测试确认按钮仍暴露“新建提醒”自动化名称和原命令，并包含固定尺寸矢量图标。
- 渲染检查确认按钮在正常与高对比度资源下图标和文字垂直居中。
- 检查 Logo 母版无文字、构图居中、颜色符合规格，并在小尺寸缩略图中可辨认。
- 构建 Release，确认 EXE、任务栏、窗口和 Inno Setup 均引用新图标。
- 重新运行相关 WPF 测试与发布构建，不改动提醒业务逻辑或用户数据。

## 非目标

- 不重新设计标题栏、按钮颜色、页面间距或其他图标。
- 不改变“新建提醒”的交互、快捷键或快速创建流程。
- 不创建品牌文字标、启动动画或营销素材。
