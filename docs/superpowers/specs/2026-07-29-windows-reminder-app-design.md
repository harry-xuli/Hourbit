# “时刻”Windows 提醒工具设计规格

- 日期：2026-07-29
- 状态：已完成交互式设计确认，等待书面规格审阅
- 平台：Windows 11
- 暂用产品名：时刻

## 1. 产品目标

“时刻”是一款本地优先的 Windows 11 提醒工具，兼顾快速提醒与简单计划。用户可以在任意软件中通过全局快捷键快速创建倒计时、指定时间闹钟或计划事项，也可以在主界面的当天时间轴中安排和处理接下来要做的事情。

第一版面向用户本人及少量同事或朋友。它提供安装版和便携版，不要求账号或云服务。架构为以后增加多设备同步预留边界，但第一版不实现同步。

### 1.1 成功标准

在应用正常驻留且电脑未睡眠时，验收测试中的到期事项必须全部触发。应用重启、电脑解锁或从睡眠恢复后，每个错过事项必须具有可追踪的处理结果。连续驻留 24 小时不得出现明显内存增长、重复提醒或调度漂移。

## 2. 第一版范围

### 2.1 包含

- 倒计时。
- 单次指定时间闹钟。
- 当天计划。
- 每天、工作日和每周重复。
- 普通 Windows 系统通知。
- 重要事项的置顶弹窗和循环响铃。
- 完成、稍后提醒和忽略操作。
- 锁屏提醒。
- 从睡眠恢复后的错过事项处理。
- 当天时间轴主界面。
- 全局快捷键呼出的智能命令条。
- 托盘驻留和可选开机启动。
- 本地数据、自动备份、手动导出与恢复。
- 按当前用户安装的安装版。
- ZIP 便携版。
- 手动检查新版本。

### 2.2 不包含

- 手机端和云同步。
- 月历、项目、子任务和多人协作。
- AI 服务和语音助手。
- 睡眠中唤醒电脑。
- 第三方日历同步。
- 静默自动更新。
- 公开商店发布、遥测和云端崩溃收集。

## 3. 用户体验

### 3.1 主界面

主界面采用“全天时间轴”布局，统一显示：

- 指定时间闹钟。
- 正在运行的倒计时。
- 当天计划。
- 由每天、工作日或每周规则生成的事项实例。
- 已完成、已忽略和已错过事项。

页面顶部显示日期、下一个提醒、今日完成数量和“新建”操作。时间轴按发生时间排序，并用图标、文字和颜色共同表达事项类型与状态。颜色不能成为唯一状态标识。

用户可在时间轴中创建、编辑、完成、推迟或删除事项。编辑重复事项时，必须选择“只修改本次”或“修改本次及以后”；删除重复事项时，必须选择“只删除本次”或“删除本次及以后”。

### 3.2 智能命令条

用户在任意软件中按全局快捷键后，屏幕中央显示一个紧凑命令条。默认快捷键为 `Ctrl+Alt+Space`，在首次启动时注册；如果被占用，应用要求用户选择新的组合键，不影响其他功能启动。

命令条接受常见中文时间表达，例如：

- “20分钟后休息”
- “下午3点半提醒我打电话”
- “明早9点开会”
- “每个工作日18点下班”
- “每周五下午4点写周报”

解析完全在本机通过确定性规则完成，不调用 AI 或网络服务。输入后显示明确预览，包括绝对日期、时间、重复规则和提醒级别。按 Enter 创建；按 Tab 展开标题、日期、时间、重复规则和提醒级别等详细字段。

“下周”“晚上”“待会”等无法唯一确定时刻的表达不得直接创建。命令条必须要求用户选择具体时间。

### 3.3 托盘

关闭主窗口只将应用隐藏到托盘，调度器继续运行。托盘菜单显示下一个提醒，并提供：

- 打开今天时间轴。
- 快速创建。
- 常用倒计时。
- 设置。
- 明确退出应用。

如果仍有未到期事项，退出操作必须告知用户退出后提醒不会触发，并要求确认。

## 4. 提醒行为

### 4.1 普通提醒

普通提醒进入 Windows 通知中心，显示事项名称、计划时间和以下操作：

- 完成。
- 10 分钟后提醒。
- 忽略。

点击通知正文打开主界面，并定位到相应事项。Windows 专注模式可能延迟或隐藏普通通知，应用不得声称普通提醒能够强制绕过系统专注设置。

### 4.2 重要提醒

重要提醒显示应用自有的置顶窗口，并循环播放声音。窗口提供：

- 完成。
- 稍后 5、10、30 或 60 分钟。
- 忽略。

窗口右上角关闭按钮等同“稍后 10 分钟”，防止误关后事项无声消失。只有明确完成、推迟或忽略后才停止响铃。重要提醒不绕过 Windows 锁屏，也不尝试唤醒睡眠中的电脑。

### 4.3 错过事项

应用在启动、解锁、从睡眠恢复、系统时间变化和时区变化后重新扫描事项。

- 错过不超过 5 分钟：立即执行原提醒行为。
- 错过超过 5 分钟的普通事项：进入一条汇总通知，并在时间轴标为“错过”。
- 错过超过 5 分钟的重要事项：仍单独显示重要提醒。

汇总通知不得导致多个普通提醒同时轰炸用户。每个错过事项都要保留处理状态。

## 5. 时间与重复语义

倒计时创建时立即换算并保存绝对到期时间。应用重启不会重置或延长倒计时。

重复定义与发生实例分离。每天、工作日和每周规则每次只生成下一个实例。本次实例被完成、忽略或标为错过后，系统再生成下一次，避免重复实例。

工作日固定为周一至周五；第一版不包含法定节假日判断。每周规则允许选择一个或多个星期。所有时间按照事项创建时的本地时区规则解释；系统时区变化后，重复事项保持相同的本地钟表时间，单次事项保持原绝对时间点。

## 6. 技术架构

### 6.1 技术路线

- UI：WPF。
- 运行时：.NET 10 LTS。
- Windows 通知：Windows App SDK `AppNotificationManager`。
- 数据库：SQLite。
- 平台目标：Windows 11 x64；架构边界不阻止以后增加 ARM64 构建。

选择 WPF 是因为该产品只面向 Windows，且托盘驻留、全局快捷键、置顶窗口、音频与安装版/便携版双分发是核心需求。Windows App SDK 可供 WPF 应用使用，并支持打包与非打包应用通知。

### 6.2 组件

应用分为以下独立组件：

1. **时间轴界面**：呈现和操作当天事项，不负责调度。
2. **智能命令条**：收集输入并显示解析预览，不直接写数据库。
3. **托盘外壳**：管理窗口显隐、托盘菜单和退出确认。
4. **时间解析器**：把中文表达转换为候选事项或明确的歧义结果。
5. **事项服务**：校验并创建、编辑、完成、推迟、忽略或删除事项。
6. **重复规则服务**：计算下一实例。
7. **调度器**：只维护一个活动调度循环，寻找下一个到期实例。
8. **提醒分发器**：根据提醒级别选择系统通知或重要提醒窗口。
9. **恢复协调器**：处理启动、解锁、唤醒、时间与时区变化后的对账。
10. **数据仓储**：封装 SQLite、事务、迁移和备份。
11. **设置服务**：管理快捷键、声音、开机启动和版本信息。

组件通过明确接口通信。界面不得直接操作 SQLite；通知按钮也必须通过事项服务改变状态。

### 6.3 数据流

创建事项的顺序：

1. 界面或命令条提交候选事项。
2. 时间解析器返回明确结果或歧义。
3. 用户确认明确预览。
4. 事项服务校验数据。
5. 数据仓储在事务中保存事项和首个实例。
6. 写入成功后通知调度器刷新。
7. 界面显示创建成功。

“先保存、后调度”是硬性规则。数据库写入失败时不得显示成功，也不得安排仅存在于内存中的提醒。

### 6.4 单实例

同一用户只能运行一个应用实例。第二次启动必须把激活参数转发给现有实例并显示主界面或命令条，不能创建第二个调度器。

## 7. 数据设计

SQLite 至少包含以下逻辑实体：

- `items`：事项主体、类型、标题、提醒级别和生命周期状态。
- `occurrences`：每次实际发生时间、处理状态和处理时间。
- `recurrence_rules`：每天、工作日或每周规则。
- `action_log`：创建、编辑、完成、推迟、忽略、错过和恢复记录。
- `settings`：快捷键、声音、开机启动、普通提醒暂停状态等。
- `schema_info`：数据库结构版本和迁移记录。

安装版数据库保存在 `%LOCALAPPDATA%\Moment\data\moment.db`。便携版通过发行包中的 `portable.flag` 标记启动，并把数据库保存在应用目录下的 `Data\moment.db`。两种模式使用相同数据库结构。

## 8. 备份与恢复

应用每天首次成功启动并打开数据库后创建一次备份，保留最近 7 份。备份通过 SQLite 一致性备份机制生成，不能直接复制正在写入的数据库文件。

用户可以导出扩展名为 `.moment-backup` 的单个备份包。备份包是包含一致性数据库快照和版本清单的 ZIP 容器，可在另一台电脑上恢复。恢复流程：

1. 校验备份格式和结构版本。
2. 自动备份当前数据。
3. 关闭调度器和数据库连接。
4. 恢复数据。
5. 运行必要迁移并进行完整性检查。
6. 重新扫描未来与错过事项。

数据库损坏时，应用先复制损坏文件以供诊断，再尝试最近的完整备份。不得直接覆盖唯一原件。

## 9. 异常处理

- **通知权限关闭**：显示持久设置提示、打开 Windows 通知设置入口和“发送测试通知”。
- **快捷键冲突**：保留应用其余功能，要求更换快捷键。
- **数据库写入失败**：保留用户输入，显示可操作错误并允许重试。
- **数据库损坏**：保存损坏副本，尝试最近完整备份。
- **声音文件失效**：退回内置默认声音并提示用户。
- **系统时间或时区变化**：停止当前计时等待，重新读取数据库并计算下一个到期实例。
- **多个事项同时到期**：按重要级别和发生时间稳定排序；普通事项可合并，重要事项逐个进入处理队列。
- **通知组件不可用**：在应用内显示故障状态；重要提醒仍使用应用自有窗口。

## 10. 安装、便携与更新

### 10.1 安装版

安装版使用 Inno Setup 生成传统 EXE 安装程序，按当前用户安装，不要求管理员权限，创建开始菜单入口和卸载入口。开机启动由用户在设置中选择，默认关闭。

### 10.2 便携版

便携版以 ZIP 发布，解压即用。数据位于同目录 `Data` 文件夹。用户移动应用目录后，应用检测旧的开机启动路径并要求重新确认。

### 10.3 更新

第一版不自动下载或安装更新。“检查更新”打开构建时配置的 HTTPS 发布页面；如果发行构建没有配置发布页面，则隐藏该操作。安装升级和便携版覆盖升级都不得删除用户数据。

少量熟人测试阶段允许使用未签名安装包，但发布说明必须提前告知 Windows SmartScreen 可能出现警告。扩大分发前必须引入代码签名。

## 11. 可访问性与视觉

- 默认文字与背景必须保持高对比度。
- 支持 Windows 100%–200% 显示缩放。
- 关键路径可以完全使用键盘完成。
- 不只依靠颜色表达类型和状态。
- 兼容 Windows 高对比度主题。
- 尊重系统“减少动画”设置。
- 提供声音试听、音量和声音选择。
- 重要提醒不得在没有明确提示的情况下成为静音。
- 所有交互控件具有可供屏幕阅读器识别的名称。

## 12. 测试与验收

### 12.1 功能

- 创建、修改和删除倒计时、闹钟和计划。
- 解析受支持的中文时间表达。
- 歧义表达必须要求确认。
- 每天、工作日和每周重复跨越周末和月末。
- 重复事项“只改本次”和“本次及以后”。
- 普通通知的完成、推迟和忽略。
- 重要提醒的置顶、循环响铃与停止条件。
- 多个事项同时到期，不重复、不丢失。

### 12.2 生命周期

- 主窗口关闭、托盘驻留时正常提醒。
- 应用重启后倒计时和计划仍准确。
- 锁屏期间正常提醒。
- 从睡眠恢复后正确处理错过事项。
- 手动修改系统时间、日期和时区后正确重算。
- 第二次启动只激活已有实例。

### 12.3 故障与数据

- 快捷键冲突。
- 通知权限关闭。
- 自定义声音文件丢失。
- 数据库写入失败。
- 数据库结构升级。
- 自动备份、导出和恢复。
- 模拟数据库损坏后的保护与恢复。

### 12.4 发布

- 安装、升级和卸载。
- 便携版解压、移动和覆盖升级。
- x64 Windows 11 上 100%、125%、150% 和 200% 缩放。
- 高对比度主题和键盘操作。
- 连续驻留 24 小时的资源与调度稳定性。

## 14. 已确认的产品决策

- 快速提醒与简单计划并重。
- 锁屏可提醒，睡眠期间不保证唤醒。
- 本地优先，并预留未来同步边界。
- 主界面管理与快捷命令条组合使用。
- 普通与重要提醒分级。
- 支持当天计划、每天、工作日和每周重复。
- 同时提供安装版和便携版。
- 主界面采用全天时间轴。
- 快速创建采用智能命令条。
- 面向少量同事或朋友分发。
- 技术路线采用 WPF、.NET 10 LTS 和 Windows App SDK 通知。
