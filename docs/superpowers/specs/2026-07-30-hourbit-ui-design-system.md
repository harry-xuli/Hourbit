# “时刻”WPF 界面实现基准

## 视觉参考

- 主时间线：`docs/superpowers/specs/assets/hourbit-main-timeline-concept.png`
- 快速添加：`docs/superpowers/specs/assets/hourbit-quick-add-concept.png`

两张概念图是已通过产品规格的视觉展开。实现必须保持信息架构、文字层级、列表密度、白底深色文字、高对比度和键盘焦点；概念图中的背景示例事项不属于应用信息架构。

## 设计令牌

- 主背景：`#FFFFFF`
- 次级背景：`#F6F8FA`
- 主要文字：`#18212F`
- 次要文字：`#4B5563`，不得使用低对比度浅白文字
- 边框：`#D7DCE3`
- 主强调色：`#0F5CC0`
- 重要提醒：`#C83B19`
- 已错过：`#C42B1C`
- 已完成：`#287A43`
- 键盘焦点：2px `#0F6CBD` 外框
- 字体：Segoe UI、Microsoft YaHei UI、sans-serif
- 正文：14–16px；行高至少 1.4
- 控件圆角：4–6px；只在输入框、按钮和有意义的选择面使用

默认文字与背景对比度至少 4.5:1；颜色不能成为唯一状态标识。

## 主时间线

- 顶栏依次显示：产品名、日期、下一个提醒、今日完成数量、“新建提醒”。
- 主体是开放式纵向时间轴，不使用卡片网格。
- 分组固定为“已错过 / 接下来 / 已完成”。
- 每行显示时间、图标、标题、重复说明、重要性、状态文字。
- 当前键盘选择行有清晰蓝色焦点框。
- 使用虚拟化列表；100%–200% 缩放不裁切主要操作。
- 快捷键：Enter 编辑、Ctrl+N 新建、Delete 删除、Ctrl+Shift+Space 完成。

## 快速添加

- 约 680px 宽，位于当前显示器中央，无任务栏按钮，打开即聚焦输入框。
- 歧义输入不得创建；显示“请选择具体时间”和全宽选择行。
- 选择后显示绝对预览：`2026年7月30日 09:00 · 单次 · 普通提醒`。
- 底部显示：`Enter 创建 · Tab 更多选项 · Esc 隐藏`。
- Escape 隐藏但不清空输入；Tab 展开详细字段。

## 组件与交互

- 主要按钮、次要按钮、危险按钮使用共享样式与明确禁用/悬停/聚焦状态。
- 状态同时使用图标、文字和颜色。
- 系统关闭客户端动画时不运行动画。
- 所有交互控件提供可供屏幕阅读器识别的名称。
- 代码后置只负责窗口位置、焦点和必须的原生生命周期；业务状态与命令放在可测试 ViewModel。

## 允许的可见文字

主时间线：`时刻`、日期、`下一个提醒`、`今日完成`、`新建提醒`、`已错过`、`接下来`、`已完成`、事项行字段和规格定义的快捷键提示。

快速添加：用户输入、`请选择具体时间`、候选时间、绝对预览、`选择时间后可按 Enter 创建`、`Enter 创建`、`Tab 更多选项`、`Esc 隐藏`。

不得添加营销文案、AI 标签、装饰性徽章、虚构统计或无规格依据的新导航。
