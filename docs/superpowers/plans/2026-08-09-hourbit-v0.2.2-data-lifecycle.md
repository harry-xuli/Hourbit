# Hourbit 0.2.2 Data Lifecycle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Guarantee empty first-run data, preserved upgrade data, reliable item deletion, and an explicit backup-first reset-to-new workflow.

**Architecture:** Keep the legacy production database path for upgrade compatibility and enforce package hygiene at build time. Implement reset as a restart-gated operation: export a verified backup, write a narrowly scoped reset request outside the database, shut down, then apply the reset before any repository opens on the next process.

**Tech Stack:** .NET 8, C# 12, WPF, SQLite, xUnit, PowerShell release scripts.

## Global Constraints

- Never silently delete `%LocalAppData%\Moment` during install, upgrade, uninstall, or normal startup.
- Reset requires a completed backup and two explicit confirmations.
- Reset may delete only the exact resolved production database, `-wal`, `-shm`, and settings files named by the reset manifest.
- Portable mode resets only its own `Data` directory.
- Existing schema and backup history remain restorable.
- Use TDD and make each task a separate commit.
