# Hourbit v0.4.0 Warm Focus UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the approved warm-focus main UI, future date navigation, global search, UI-only Chinese/English switching, pending-only todo panel, tray double-click restore, unified shortcuts, and public Moment-to-Hourbit repository rename without breaking upgrade compatibility.

**Architecture:** Keep the existing local-first domain and SQLite schema. Add presentation-only localization resources and search/query seams, reuse the existing timeline coordinator and analytics navigation, and perform the public assembly rename with explicit compatibility constants for old data and installation identities.

**Tech Stack:** .NET/WPF, C#, SQLite, xUnit, Windows Forms NotifyIcon, Inno Setup, PowerShell release scripts.

## Global Constraints

- Windows 11 x64; no new runtime dependency.
- Timeline period modes remain Day, ISO week Monday–Sunday, and calendar month; no year mode.
- UI language codes are exactly `zh-CN` and `en-US`.
- Language switching never translates or rewrites user-authored content.
- `%LocalAppData%\Moment\data\moment.db`, `.moment-backup`, the existing Inno AppId, legacy startup names, notification groups, and single-instance identities remain compatible.
- Current public repository, product, projects, assemblies, namespaces, installer entry point, and manuals use Hourbit.
- TDD is required for every behavior change.
