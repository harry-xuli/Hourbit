# Hourbit 0.2.2 Reminder Reliability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make quick-entry time parsing, recurrence, visible delivery, missed classification, editing, deletion, and timeline refresh reliable.

**Architecture:** Persist delivery attempts as explicit occurrence states in schema v5, use compare-and-set transitions around delivery, and create the recurring successor in the same transaction that records successful delivery. Route every due reminder through an in-app presenter while keeping Windows notifications as an auxiliary channel; render only persisted states in the timeline.

**Tech Stack:** .NET 8, C# 12, WPF, SQLite, Windows App SDK notifications, xUnit.

## Global Constraints

- Windows 11, local-only data, 24-hour display.
- Keep `%LocalAppData%\Moment\data\moment.db`, the existing Inno AppId, and internal `Moment.*` identities for upgrade compatibility.
- Never mark an occurrence `Fired` until at least one visible delivery channel accepts it.
- Never infer `Missed` from `DueAt < now` in the UI.
- Do not resume PDF Task 6 or deferred Task 7 work.
- Use TDD and make each task a separate commit.

- [ ] **Step 4: Implement the state machine**

For each due or retryable reminder:

```csharp
if (!await repository.TryBeginDeliveryAsync(id, now, ct)) return;
try
{
    await sink.DeliverAsync(reminder, ct);
    var next = reminder.Item.Recurrence is { } rule
        ? ReminderOccurrence.Schedule(
            reminder.Item.Id,
            recurrenceCalculator.NextAfter(rule, reminder.Occurrence.DueAt, zone))
        : null;
    await repository.CompleteDeliveryAsync(id, now, next, ct);
}
catch (Exception ex) when (ex is not OperationCanceledException)
{
    var retryAt = policy.GetNextRetryAt(attempt, now);
    await repository.RecordDeliveryFailureAsync(id, now, ex.GetType().Name, retryAt, ct);
}
```

Always raise `StateChanged` after a committed transition.
