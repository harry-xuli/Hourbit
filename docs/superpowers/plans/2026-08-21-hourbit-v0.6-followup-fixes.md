# Hourbit v0.6 Follow-up Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make missed reminders actionable, stop completed countdowns, simplify and reorder to-dos, and finish Chinese/English localization for timeline groups and date controls.

**Architecture:** Preserve schema v6 and all existing reminder/todo records. Extend existing action/state contracts, store only to-do presentation order in the settings table, and keep one shared `ILocalizationService` as the UI-language source. UI changes remain in the timeline/date/report views; scheduling remains in Core/Infrastructure.

**Tech Stack:** .NET 10, WPF, SQLite, xUnit.

**Spec:** User-approved requirements recorded in this task on 2026-08-21 plus `docs/superpowers/plans/2026-08-15-hourbit-language-calendar-followup.md`.

## Global Constraints

- Work from `main` schema v6; never remove schema markers or downgrade user data.
- Language switching changes application UI only, never user-entered titles.
- A successful action refreshes scheduling; failed actions do not fabricate UI state.
- To-do ordering is presentation metadata and must not alter due dates or completion history.
- Run real behavior tests first and observe RED before production changes.
