# Hourbit 日程

Hourbit 日程是一款面向 Windows 11 的本地提醒与待办应用。它支持倒计时、
闹钟、计划、无日期待办和有截止日期的全天待办；数据保存在本机，不需要账号。
当前版本和发布日期由仓库根目录的 `Version.props` 唯一定义。

当前开发与发布状态见 [开发进度](docs/progress.md)。

## 快速录入

输入内容后，Hourbit 会按是否含有明确时间创建不同项目：

- 有日期和时间：创建定时提醒，例如 `提交周报 2026-08-05 14:30`。
- 只有时间：按今天或下一个有效时间创建提醒，例如 `喝水 23:00`。
- 只有日期：创建有截止日期、但不会响铃的待办，例如 `续费 2026/08/05`。
- 没有日期和时间：创建无日期待办，例如 `整理书架`。

支持的绝对日期包括：

- 年月日：`2026-08-05`、`2026/08/05`、`2026.08.05`、`2026年8月5日`；
- 年份在末尾的数字日期：按照 Windows 当前区域的短日期顺序解释。例如
  `03/04/2026` 在 `en-US` 下是 3 月 4 日，在 `en-GB` 下是 4 月 3 日；
- 已有相对日期表达：例如 `今天`、`明天`。

时间使用 24 小时显示，支持 `14:30`、`14点30分`、`23点`，并兼容
`下午2点`、`晚上8点半`。有效范围是 `00:00` 至 `23:59`。

## 待办规则

- 全天待办不会进入提醒调度器，也不会发送 Windows 通知。
- 有截止日期的待办过期后保留在列表中并显示 `已逾期`，直到完成或删除。
- `每天锻炼`、`每周一整理房间` 等不含明确时间的文字会原样保存为普通待办；
  当前版本不支持重复待办。
- 编辑待办时添加时间会转换为提醒；编辑提醒时移除时间会转换为待办。
- 主列表采用紧凑布局，不显示日期文字；日期仍可在编辑窗口和读屏信息中查看。

## 复制、倒计时与帮助

- 选中提醒或待办后点击“复制（Ctrl+D）”，可修改副本后创建新记录，原记录不变。
- 托盘常用倒计时会在时间线动态显示剩余时间，到期显示“已到时”。
- 主界面 `?` 按钮和托盘“使用说明”会打开应用内帮助窗口。

## 安装、便携版与兼容性

发布产物为 `Hourbit-Setup-x64.exe` 和 `Hourbit-Portable-x64.zip`，发布程序为
`Hourbit.exe`。代码、解决方案和项目名称均已统一为 `Hourbit.*`。安装版继续使用
既有安装 AppId、`Moment` 数据目录、数据库位置、启动项迁移键和单实例标识，以便
从旧版本原地升级并保留提醒与设置；这些旧名称仅是兼容标识，不是产品展示名称。

Windows 可能会对未签名测试构建显示安全提示。不要为了安装测试构建而关闭或绕过
Smart App Control、Microsoft Defender 或其他 Windows 安全功能；正式分发应使用
可信代码签名。

## 构建与验证

需要 .NET SDK 和 Inno Setup 6：

```powershell
dotnet test Hourbit.slnx --configuration Release --no-restore
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-release.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\smoke-test.ps1
```

完整冒烟测试只在系统临时目录创建隔离数据库，验证旧 schema v1/v2 升级、提醒
保留、待办持久化与调度隔离，并核对 EXE、安装包、设置页脚和发行文件的版本身份。
它不会读取或覆盖正式安装的数据。

## 发布版本

未来发布只修改仓库根目录的 `Version.props`。产品名、可执行文件名、语义版本和
发布日期均从该文件进入程序集、设置页、安装器和发行脚本；不要在其他文件维护第二
份版本号。每次发布都必须完成 [发布检查表](docs/release-checklist.md)。
